# Personal Tax Calculator

A **Next.js + TypeScript + Tailwind CSS** web app that calculates your personal income tax based on South African tax brackets. It shows **tax owed**, **net income**, and a **visual pie chart** of the breakdown.

This project demonstrates **frontend development skills**, **financial logic**, and **data visualization** — perfect for a developer portfolio.

---

## Features

- Input your **annual income**.
- Calculate **tax owed** using progressive tax brackets.
- Display **net income** after tax.
- **Pie chart** showing the proportion of tax vs net income.
- Responsive and **interactive design** with Tailwind CSS.

---

## Tech Stack

- [Next.js](https://nextjs.org/) – React framework for server-side rendering and routing
- TypeScript – Strongly typed JavaScript
- Tailwind CSS – Utility-first CSS framework for styling
- [Recharts](https://recharts.org/) – React charting library for the pie chart
